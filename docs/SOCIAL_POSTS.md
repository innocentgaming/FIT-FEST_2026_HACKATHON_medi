## 💼 LinkedIn Submission Post

🚀 Excited to unveil **MediLink — CARE** (Coordinated Assistance & Record Engine), built for the **FIT-FEST 2026 Hackathon** at **Flora Institute of Technology**!

🏥 **The Challenge**: Regional healthcare coordination is severely hindered by siloed resource data, frantic searches for compatible blood units, uncoordinated ambulance dispatching, and abandoned hospital admission rejections.

💡 **Our Solution**: **MediLink CARE** creates a single, real-time coordination bridge connecting Patients, Hospitals, Ambulance Drivers, Command Admins, and System Doctors:
- 🚨 **Emergency Mode Command Center**: 1-click auto-dispatch calculating nearest available ambulances and emergency facility matching.
- 🩸 **Smart Blood Requirement Matcher**: Instant cold-storage stock verification across all 8 blood groups based on urgency.
- 🚑 **Live Ambulance Fleet Tracking**: Real-time simulated GPS tracking with interactive Leaflet radar and 7-step dispatch milestone progression.
- 🏥 **Live Hospital Resource Telemetry**: Sub-millisecond broadcast of available beds, ICU, ventilators, and oxygen capacity.
- ⚖️ **Admin Triage & System Doctor Conflict Resolution**: Zero lost emergencies — rejected requests are triaged to System Doctors for re-routing to alternative facilities.
- 🔒 **Enterprise-Grade Security & WCAG 2.1 AA Accessibility**: Server-side RBAC, IDOR protection, non-diagnostic safety guard, and 258 automated test cases (100% pass rate).

🛠️ **Tech Stack**: React 18, Vite, Node.js, Express, Socket.io, Docker, Google Cloud Run.

Special thanks to **Flora Institute of Technology** and the organizing team at **@GDG.FIT.PUNE**!

🔗 **GitHub Repository**: https://github.com/innocentgaming/FIT-FEST_2026_HACKATHON_medi
